# TrustRS 2026

Static export of the published Google Sites page:

https://sites.google.com/view/trustrs2026

## Deploy on GitHub Pages

1. Push this repository to GitHub.
2. Open repository settings.
3. Go to `Pages`.
4. Select `Deploy from a branch`.
5. Choose the branch you pushed, and use `/ (root)` as the publishing folder.

The deployable files in the repository root are copied from `Takeout/云端硬盘/TrustRS 2026/PUBLISHED`.
`HomePage.html` is duplicated as `index.html` so GitHub Pages can serve the homepage from the site root.
